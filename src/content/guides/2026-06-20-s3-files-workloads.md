Amazon S3 Files gives applications a POSIX file-system interface backed by durable object storage.

This hub entry points to CLI walkthroughs for EC2 and Lambda (setup through teardown) and Terraform examples for EC2, ECS Fargate, and Lambda using the terraform-aws-s3-files modules.
